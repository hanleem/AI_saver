# AI_saver 시작하기 — Claude Code 편

프로그래밍을 몰라도 따라 할 수 있게 썼습니다. 명령어는 그대로 복사해서 붙여넣으면 됩니다.

## 이게 뭘 해주나요

Claude Code로 작업한 기록을 보고, "이번 달엔 이런 습관 때문에 오래 걸렸어요"를 알려줍니다.
그리고 너무 막연한 요청("전체 다 고쳐줘")을 하면, 하기 전에 "어디까지 할까요?" 하고 4개 중 골라달라고 물어봅니다.

**아무것도 설치 전에 확인만 해보고 싶다면** 1번(설치)과 2번(기준선 만들기)만 하고 멈추세요. 아직 아무것도 바뀌지 않습니다. 그냥 지금까지 기록을 보여줄 뿐입니다.

## 준비물

- Claude Code가 이미 설치돼 있어야 합니다.
- Python이 컴퓨터에 있어야 합니다. 터미널(까만 화면)에 아래를 쳐서 확인하세요.

```bash
python --version
```

`Python 3.10` 이상이 나오면 됩니다. 없다면 [python.org](https://www.python.org/downloads/)에서 내려받아 설치하세요(설치할 때 "Add python to PATH" 체크박스를 꼭 눌러주세요).

## 1. 설치

터미널에 아래 두 줄을 순서대로 붙여넣으세요.

```bash
claude plugin marketplace add hanleem/AI_saver
claude plugin install ai-saver@ai-saver
```

이걸로 끝입니다. 아직 아무 일도 일어나지 않습니다 — AI_saver는 처음엔 **조용히 지켜보기만** 합니다.

## 이 아래 명령어를 쓰는 두 가지 방법

이 문서에는 `ai_saver_cli.py backfill` 같은 명령어가 여러 번 나옵니다. 둘 중 편한 쪽으로 하세요.

### 방법 A — Claude Code에게 그대로 시키기 (제일 쉽고 실수가 없습니다)

터미널을 직접 만지지 않고, **Claude Code 채팅창에 그대로 문장으로 말합니다.**

> AI_saver의 backfill을 실행해줘

Claude Code가 알아서 설치된 폴더를 찾아 실행해줍니다. 이 문서에서 `python ...py backfill` 같은 게 나오면, 그냥 `AI_saver의 backfill을 실행해줘`처럼 말로 바꿔서 채팅에 넣으면 됩니다. **이 글을 처음 읽는 분께는 이 방법을 권합니다.**

### 방법 B — 터미널에 직접 치기

터미널에 익숙하면 이 방법이 더 빠릅니다. **폴더 위치로 한 번만 이동해두면**, 그 뒤로는 경로를 매번 안 적어도 됩니다.

```bash
cd "AI_saver가 설치된 폴더"
```

설치된 폴더가 어딘지 모르면 Claude Code에게 물어보세요.

> AI_saver 플러그인이 설치된 폴더 경로를 알려줘

폴더로 이동했으면, 이 문서의 모든 명령어에서 `python ai_saver_cli.py ...`를 아래처럼 바꿔 씁니다.

```bash
python scripts/ai_saver_cli.py backfill
```

> ⚠️ **따옴표를 쓰지 마세요.** `"경로/scripts/ai_saver_cli.py" backfill`처럼 앞뒤에 따옴표를 넣다가 한쪽을 빠뜨리면, 파일 이름 뒤에 `backfill`까지 붙어버려서 `can't open file '...ai_saver_cli.py backfill'` 같은 오류가 납니다. 위처럼 **폴더로 이동한 다음, 따옴표 없이** 치면 이런 실수가 아예 안 생깁니다.

아래부터는 방법 A(말로 시키기) 기준으로 설명합니다. 터미널로 직접 하실 분은 각 문장을 "방법 B" 명령어로 바꿔서 실행하세요.

## 2. 기준선 만들기 — 가장 먼저 할 일

지금까지 Claude Code로 작업한 기록이 컴퓨터에 이미 있습니다. 그걸로 첫 리포트를 만들어봅니다.

> AI_saver의 backfill을 실행해줘

*(터미널: `python scripts/ai_saver_cli.py backfill`)*

끝나면 리포트를 봅니다.

> AI_saver의 이번 달 리포트를 보여줘

*(터미널: `python scripts/ai_saver_cli.py report`)*

**이 리포트에 토큰이니 뭐니 하는 숫자는 안 나옵니다.** "로그인 화면 고칠 때마다 파일을 6번 다시 읽었어요" 같은, 사람이 읽어서 바로 이해되는 문장으로 나옵니다.

## 3. 2주 동안은 그냥 씁니다

이 기간 동안 AI_saver는 매번 판정만 하고 **끼어들지 않습니다.** 켜기 전에 "얼마나 자주 끼어들게 될지"를 먼저 확인하기 위해서입니다. 너무 자주 끼어들면 귀찮아서 꺼버리게 되고, 그러면 도구가 있으나 마나 해집니다.

지금 상태를 보고 싶으면:

> AI_saver 상태 보여줘

*(터미널: `python scripts/ai_saver_cli.py status`)*

## 4. 2주 뒤 — 실행 전 확인 켜기

> AI_saver calibrate 실행하고, gate 켜줘

*(터미널: `python scripts/ai_saver_cli.py calibrate` 다음 `python scripts/ai_saver_cli.py gate on`)*

`calibrate`가 먼저 "이 정도 기준이면 전체 요청의 10% 정도만 끼어들겠다"로 기준을 맞춰줍니다. 그다음 `gate on`으로 켭니다.

켜고 나면 이렇게 막연한 요청을 할 때만 물어봅니다:

```
전체 앱 디자인 다 예쁘게 바꿔줘
```

```
⚠ 작업량이 클 수 있습니다

A. 이 요소만 바꾸기      ★
B. 이 화면 전체 맞추기   ★★   ← 추천
C. 앱 전체 통일          ★★★★
D. 먼저 시안만 보기      ★
```

숫자 대신 별표(★)로 표시됩니다. 별이 많을수록 시간이 오래 걸리는 작업입니다. 추천이 항상 하나 붙어 나오니, 뭘 골라야 할지 모르겠으면 추천을 고르면 됩니다.

## 5. 매달 리포트 보기

한 달에 한 번, 이렇게 말하세요.

> 이번 달 AI_saver 리뷰 해줘

같은 습관이 5번 이상 반복되면 리포트에 이렇게 뜹니다.

```
### `/focus-file` (아직 없음, 96번 반복)
- 만들어지면 하는 일: 지목한 파일만 읽고, 그 파일을 다시 열지 않는다.
```

**이건 아직 실제 명령어가 아닙니다.** 이름만 제안된 상태라, 지금 `/`를 쳐도 안 뜹니다. "만들어지면 하는 일"에 적힌 게 그 명령어가 생기면 앞으로 지켜질 규칙입니다.

실제로 만들고 싶으면 이렇게 말하세요.

> skill-promote 해줘. focus-file 만들어줘

만들어지고 나면 **그 즉시** `/focus-file`이 자동완성에 뜹니다. 재시작할 필요도 없습니다. 한번 쳐서 확인해보세요.

**진짜 도움이 됐는지는 안 세도 됩니다.** 만든 시점의 습관 빈도를 AI_saver가 같이 기록해두고, 14일 뒤부터 리포트에 자동으로 이렇게 뜹니다.

```
## 승격한 명령어, 효과가 있었나

- `/focus-file` — 효과가 있습니다 (하루 발생률 82% 감소). 계속 쓰세요.
- `/quick-test` — 효과가 뚜렷하지 않습니다 (거의 그대로). 지워도 됩니다.
```

효과가 없다고 나오면 리포트가 알려주는 폴더(`~/.claude/skills/<이름>/`)를 지우면 됩니다. 안 써보면 도움이 됐는지 알 수 없으니, 5번 이상 반복된 습관은 일단 만들어보고 이 판정에 맡기는 게 낫습니다.

## 끄고 싶으면

> AI_saver gate 꺼줘

*(터미널: `python scripts/ai_saver_cli.py gate off`)*

완전히 지우고 싶으면:

```bash
claude plugin uninstall ai-saver
```

기록은 저장소가 아니라 `~/.claude/ai-saver/` 폴더에 따로 있습니다. 지우고 싶으면 이 폴더를 통째로 삭제하면 됩니다.

## 개인정보

- 프롬프트 원문은 저장하지 않습니다. 짧은 지문(해시)만 남습니다.
- 인터넷으로 아무것도 전송하지 않습니다. 전부 내 컴퓨터 안에서만 계산됩니다.

## 막히면

- `python`이 없다는 오류 → 파이썬 설치 후 터미널을 완전히 껐다 다시 켜세요.
- `can't open file '...backfill'`처럼 파일 이름 뒤에 명령어가 붙어 나오는 오류 → 위 "방법 B"의 따옴표 경고를 보세요. 폴더로 `cd`한 다음 따옴표 없이 치면 해결됩니다.
- 리포트가 비어 있다는 오류 → `backfill`을 먼저 실행했는지 확인하세요.
- 그 외 → 오류 메시지를 그대로 복사해서 Claude Code 채팅에 붙여넣고 물어보세요. 이게 제일 빠릅니다.
