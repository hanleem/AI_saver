# 월간 리뷰

집계는 이미 끝나 있다. 숫자를 다시 세지 말고, 만들어진 표를 **해석**만 한다.

## 1. 리포트 생성

```bash
python "${CLAUDE_PLUGIN_ROOT}/scripts/ai_saver_cli.py" report
```

원장이 비어 있으면 먼저 `backfill`을 돌린다. 트랜스크립트를 읽을 뿐 모델을 쓰지 않는다.

## 2. 습관 3개만 고른다

리포트 상위 3개만 다룬다. 전부 나열하면 사용자는 아무것도 안 고친다.

각 습관마다 세 줄로:
- **무슨 일이 있었나** — 파일명·횟수 같은 구체적 사실 하나
- **왜 비쌌나** — 한 줄
- **다음엔 이렇게** — 그대로 복사해 쓸 수 있는 프롬프트 문장

## 3. 개선 프롬프트는 반드시 검증한다

좁힌 프롬프트가 작업을 **실패시키면** 재시도가 늘어 손해다.
`prompt-optimizer` skill이 설치돼 있으면 그 절차(먼저 contract를 고정하고 나서 줄이기)를 따른다. 없으면 직접 확인한다:

1. 이 프롬프트로 **반드시 달성해야 할 것**을 먼저 적는다
2. 그 다음 범위를 좁힌다
3. 좁힌 뒤에도 1번이 달성 가능한지 확인한다

## 4. 개입 빈도 재조정

```bash
python "${CLAUDE_PLUGIN_ROOT}/scripts/ai_saver_cli.py" calibrate
```

개입률이 목표(10%)보다 높으면 기준점을 올린다. **귀찮아서 훅을 꺼버리면 절감은 0이 된다.**

## 5. 보고

- 토큰 숫자를 쓰지 않는다. `--technical`을 명시적으로 요청했을 때만 부록을 보여준다.
- `UNDERSCOPED_FAIL`이 늘었으면 추천이 너무 좁다는 뜻이다. 그대로 보고한다.
- 3개월 연속 절감이 미미하면 **끄는 것을 권한다.**
