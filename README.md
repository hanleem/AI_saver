# AI_saver

실제 사용 기록에서 낭비 습관을 찾아, 비싼 요청 전에 범위를 좁히고, 반복 작업을 `/명령어`로 승격합니다.

다른 토큰 도구와 다른 점은 하나입니다. **설정이 아니라 기록을 봅니다.**

```
사용 기록 → 낭비 습관 탐지 → 실행 전 4지선다 → 반복 작업 승격 → 다음 달 더 적게
```

## 설계 원칙: 계측은 공짜여야 한다

토큰을 아끼는 도구의 관측 레이어가 토큰을 쓰면 자기모순입니다.
그래서 **집계도 판정도 모델을 부르지 않습니다.**

| 레이어 | 언제 | 모델 호출 |
|---|---|---|
| 집계 (`meter`) | 세션 종료 시 자동 | **0회** |
| 판정 (`gate`) | 프롬프트마다 | **0회** |
| 개입 | 위험도 HIGH일 때만 | 질문 1회 |
| 해석 (`token-review`) | 월 1회 | 1회 |

LOW 프롬프트에는 **단 1토큰도 추가되지 않습니다.**

## 설치

```bash
claude plugin marketplace add hanleem/AI_saver
claude plugin install ai-saver@ai-saver
```

또는 저장소를 직접 클론해서 씁니다.

```bash
git clone https://github.com/hanleem/AI_saver.git
```

플러그인이 `UserPromptSubmit`(판정)과 `SessionEnd`(집계) 훅을 등록합니다. Python 3.10+ 필요, 표준 라이브러리만 씁니다.

## 처음 할 일 — 기준선부터

```bash
python ~/.claude/plugins/.../ai-saver/scripts/ai_saver_cli.py backfill
```

트랜스크립트는 **이미 디스크에 있습니다.** 그래서 아무것도 바꾸기 전에 지난 두 달 리포트가 바로 나옵니다.
기준선이 없으면 나중에 "이 도구가 도움이 됐는가"를 증명할 수 없습니다.

```bash
python .../ai_saver_cli.py report          # 이번 달 리포트
python .../ai_saver_cli.py report -t       # 숫자 부록까지
python .../ai_saver_cli.py status          # 현재 상태
python .../ai_saver_cli.py calibrate       # 개입 빈도 조정
python .../ai_saver_cli.py gate on|off     # 실행 전 확인 켜기/끄기
```

## 적용 범위 — 전역, 단 처음 2주는 관찰만

**전역 설치를 권합니다.** 낭비 습관은 저장소가 아니라 사람의 성질입니다. 파일 이름을 안 대는 사람은 어느 프로젝트에서나 안 댑니다. 프로젝트별로 쪼개면 5회 반복이 2회씩 흩어져 패턴이 보이지 않습니다.

**기본값은 shadow mode입니다** (`gate_enabled: false`). 판정하고 기록하되 끼어들지 않습니다.
2주쯤 지나 `status`의 개입 예상률을 보고 납득이 되면 켜십시오.

```bash
python .../ai_saver_cli.py calibrate   # 개입률을 10% 밑으로 맞춘다
python .../ai_saver_cli.py gate on
```

개입률 상한이 이 제품의 생명줄입니다. 귀찮아서 훅을 끄면 절감은 0이 됩니다.

## 로그 위치와 프라이버시

```
~/.claude/ai-saver/
├─ ledger/2026-09.jsonl    기계가 쓰는 원장
├─ reports/2026-09.md      사람이 읽는 리포트
└─ profile.json            기준점·모드
```

`AI_SAVER_HOME` 환경변수로 옮길 수 있습니다.

- **프롬프트 원문은 저장하지 않습니다.** 해시 12자와 길이만 남습니다(`store_prompts: false`). 원문을 보관하려면 `profile.json`에서 명시적으로 켜야 합니다.
- **전송 코드가 아예 없습니다.** 이 저장소에는 `urllib`·`requests`·소켓을 쓰는 줄이 한 줄도 없습니다. 파일을 읽고 쓰는 것이 전부입니다.
- 원장에는 작업 폴더 경로가 남습니다. 로컬에만 있지만, **리포트는 폴더 이름만** 보여줍니다 — 리포트는 남에게 보여줄 가능성이 있는 유일한 파일이기 때문입니다.
- 저장 위치는 저장소 바깥(`~/.claude/ai-saver/`)입니다. `.gitignore`에도 막아 두었습니다.

## 실행 전 확인은 이렇게 보입니다

```
⚠ 작업량이 클 수 있습니다 (전체 범위, 대상 파일 미지정)

A. 이 요소만 바꾸기      ★
B. 이 화면 전체 맞추기   ★★   ← 추천
C. 앱 전체 통일          ★★★★
D. 먼저 시안만 보기      ★

B 추천 — 이번 요청에는 프로젝트 전체를 볼 필요까지는 없어 보입니다.
```

선택지는 작업 종류(코드·디자인·오류·리서치·데이터)에 따라 달라집니다. 추천은 항상 하나, 사유는 한 줄입니다. 초보자는 어느 범위가 맞는지 자체를 모르기 때문입니다.

## 자기 교정

좁게 추천했다가 같은 요청이 다시 나오면 `UNDERSCOPED_FAIL`로 기록됩니다.
이 신호가 없으면 코치는 **무조건 최소 범위를 추천하는 쪽으로 퇴화**합니다 — 턴당 싸고 완료 작업당 비쌉니다.
목표는 토큰이 아니라 **완료한 작업당 비용**입니다.

## 한계 (먼저 밝힙니다)

1. **성공 판정은 추정입니다.** 쓴 양은 정확하지만, 그중 무엇이 꼭 필요했는지는 기계가 모릅니다. 리포트에 추정이라고 표시합니다.
2. **Claude Code 전용입니다.** 다른 도구에는 이런 트랜스크립트가 없습니다.
3. **락인 조항이 없습니다.** 3개월 절감이 상시 비용보다 작으면 이 도구를 끄라고 권고합니다.
